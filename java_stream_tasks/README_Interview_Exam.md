# Java Stream API Interview Exam — Solutions

This folder contains a Java 8+ solution for all 10 questions from the Java Stream API Problem Solving Interview Exam PDF.

## File
- `JavaStreamAPIInterviewExam.java`: complete runnable solutions for questions 1–10.

## Run
From this folder, compile and run:

```bash
javac JavaStreamAPIInterviewExam.java
java JavaStreamAPIInterviewExam
```

## Topics covered
1. First non-repeated character
2. Duplicate elements
3. Second-highest distinct number
4. Case-insensitive word frequency
5. Longest string (first one wins ties)
6. Average salary by department
7. Highest-paid employee per department
8. Common distinct list elements, preserving first-list order
9. Top 3 numbers by frequency, with numeric tie-break
10. Top 3 highest-paid employees per department, with alphabetical tie-break

The implementation uses Java 8 Stream API and avoids traditional loops for processing collections.
